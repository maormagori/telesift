# TeleSift

TeleSift is an early-stage self-hosted service that turns media from Telegram chats available to a user account into searchable releases for media managers.

The first release will focus on TV episodes and integrate with Sonarr and Prowlarr through Torznab and qBittorrent-compatible APIs.

> TeleSift is under development and is not usable yet.

Use TeleSift only with sources and content you are authorized to access.
